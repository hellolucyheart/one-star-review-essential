A program that writes one original deadpan one-star review (at most 160 characters) of an everyday essential to `/output/entry.txt` for make.fun's "One-Star Review of Something Essential" bounty. The review is the whole entry: a complaint filed in earnest against oxygen — invisible, addictive, and impossible to live without — with the sting arriving in the last few words: *"Oxygen: one star. Completely invisible, yet somehow I am addicted to it and I die without it. Worst subscription model ever."* It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
